# 🚀 Data Science Practice & Learning Journey

Selamat datang di repositori catatan harian dan mini projek *Data Science* saya! Repositori ini dibuat untuk mendokumentasikan proses belajar, eksplorasi data, dan implementasi berbagai algoritma *Machine Learning*.

---

## 📂 Struktur Repositori

Repositori ini dibagi menjadi beberapa direktori berdasarkan topik dan tingkat pembelajarannya:

| No | Folder / Topik | Deskripsi Singkat |
| :--- | :--- | :--- |
| 1 | **[01-exploratory-data-analysis](./01-exploratory-data-analysis)** | Latihan pembersihan data, statistik deskriptif, dan visualisasi data (EDA). | 
| 2 | **[02-supervised-learning](./02-supervised-learning)** | Implementasi algoritma supervised learning (Linear Regression,Logistic Regression, Decision Tree, dll). |
